Ответы на практическое задание загружается в виде файла-отчета в формате MS Word или pdf в соответсвующее задание в edu.susu.ru.

Для задания 5 сделать следующие тесты:

    Сделать команды из статьи https://statsandr.com/blog/anova-in-r. Пояснить,что показывает каждый график. Для каждого теста дать описание (на русском языке): название и суть теста, нулевая гипотеза.
    Рассчитать статистические характеристики ряда flipper_length_mm для каждого вида пингвинов с помощью функций mean(), median(), sd(), prop.table(), var(), IQR(), summary().
