1. Сделать команды из статьи <https://statsandr.com/blog/anova-in-r>. Пояснить,что показывает каждый график. Для каждого теста дать описание (на русском языке): название и суть теста, нулевая гипотеза.
2. Рассчитать статистические характеристики ряда flipper_length_mm для каждого вида пингвинов с помощью функций mean(), median(), sd(), prop.table(), var(), IQR(), summary().

1. Поясните работу функции prop.table() и IQR()
