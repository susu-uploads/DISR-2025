6.1. Проведение МНК для парной линейной регрессии с помощью lm(). Анализ качества 
построенной модели. 
1)  Скачайте файл auto.csv 
2) Загрузите данные из этого файла в датасет. 
3) Сделайте summary для Вашего датасета. Обратите внимание, что некоторые колонки (факторы) 
отмечены как строковые (character), хотя должны быть числовыми. Подумайте, в чем причина 
(вместо числовых данных некоторые данные нечисловые).  
4) Удалите из датасета столбцы, которые содержат только строковые значения. 
5) Замените нечисловые данные на NA. Выведите на экран строки, в которых есть значение NA 
(можно использовать функцию is.na) 
6) Удалите строки с NA из датасета. 
7) Сделайте матрицу корреляции с визуализацией для числовых данных, используя ggpairs() 
8) Создайте набор данных correl, состоящий из 2 столбцов: predictor - имя предиктора, coeff_corr - 
коэффициент корреляции предиктора с mpg. Подумайте, как это сделать автоматически, не вводя 
имена предикторов вручную. Используя датасет correl, выберите предиктор (столбец. фактор), 
который имеет наибольший по модулю коэффициент корреляции с откликом mpg. 
9) Постройте диаграмму рассеивания для mpg  и выбранного Вами предиктора.  
10) Рассчитайте уравнение простой линейной парной регрессии, используя функцию lm(), 
результат lm() сохранить в переменной lm_pair. 
11) Сделать summary для lm_pair. Пояснить все значения в выдаче. 
12) Написать линейное уравнение для парной регрессии для mpg, используя summary из п. 11. 
Добавить линию регрессии на диаграмму рассеяния (использовать abline). Есть ли линейная связь 
между предиктором и откликом? Каково направление связь между предиктором и откликом 
(положительная/отрицательная; линейная/нелинейная)? 
13) Вывести скорректированный коэффициент детерминации R2 для lm_pair (взять из выдачи 
summary). Сделать вывод, насколько хорошо lm_pair объясняет вариацию mpg. 
14) Вывести F-статистику для lm_pair (взять из выдачи summary). Сделать вывод о значимости 
уравнения по критерию Фишера. 
15) Постройте доверительные интервалы для коэффициентов регрессии c помощью функции 
confint() с уровнем значимости 0.01. Сделайте вывод об их значимости. 
16) Чему равно модельное значение mpg, если предиктор имеет значение, равное медиане? 
(используйте функцию predict) 
17) Постройте 5-процентные доверительные интервалы для среднего "confidence" и 
индивидуального "prediction" прогнозных значений, если предиктор имеет значение, равное 
медиане. Почему интервал для prediction шире, чем confidence? Если значимость уравнения 
регрессии снизится, то как это отразится на доверительные интервалы для прогноза? 
18) Разделите экран на 4 части с помощью par(mfrow=c(2,2)). Выведите диагностические графики с 
помощью plot(lm_pair). Для каждого графика дайте пояснение, что на нем изображено; на что 
обращать внимание. 
19) Вернитесь обратно в одно графическое окно par(mfrow=c(1,1)). Для каждого значения 
предиктора рассчитайте остаток по уравнению регрессии. Выведите график зависимости остатков 
регрессии от предиктора типа такого (см. рисунок ниже), можно использовать plot. Сделать 
вывод, есть ли какие-то аномалии в остатках (например, неравномерность распределения). Если 
аномалии есть, то пояснить возможные причины. 
 
20) Для каждого значения предиктора рассчитайте прогнозное значение mpg по парной 
регрессии, доверительные интервалы для среднего "confidence" и индивидуального "prediction" 
прогнозных значений. Постройте график с диаграммой рассеивания, уравнения регрессии, 
доверительными интервалами для confidence и prediction (как на рисунке ниже).

6.2. Расчет параметров модели множественной регрессии. Анализ качества построенной 
модели. Устранение мультиколлинеарности посредством step() и vif().

сохраните в переменной lm_multi. 
2) Сделать summary для lm_multi. Пояснить все значения в выдаче. 
3) Написать линейное уравнение для регрессии lm_multi, используя summary. 
4) Вывести скорректированный коэффициент детерминации R2 для lm_muti (взять из выдачи 
summary). Сделать вывод, насколько хорошо lm_multi объясняет вариацию mpg. Сравнить 
результат с lm_pair: какая регрессия лучше описыаает вариацию mpg. 
5) Вывести F-статистику для lm_muti (взять из выдачи summary). Сделать вывод о значимости 
уравнения по критерию Фишера. Как рассчитывается число степеней свободы для F-критерия? 
6) Вывести доверительные интервалы для коэффициентов регрессии с уровнем значимости 5%. 
Какие коэффициенты оказались не значимы на данном уровне? О чем это может

7) Рассчитать определитель матрицы парных корреляций для предикторов. Если определитель

такое AIC, привести математическую формулу.  
10) Вывести summary для модель после пошагового отбора переменных. Сравнить 
скорректированный коэффициент детерминации до и после пошагового отбора переменных. 
Сделать вывод об эффективности step. 
11) Для модели после пошагового отбора переменных написать линейное уравнение. Рассчитать 
остатки по модели для каждого наблюдения (строчки датасета). Вывести 3 наблюдения с

13) Рассчитайте прогнозное значение mpg для модели после пошагового отбора переменных при

14) Постройте 5-процентные доверительные интервалы для среднего "confidence" и 
индивидуального "prediction" прогнозных значений mpg для модели после пошагового отбора
