Задание 7
Рекомендуемые источники для подготовки
1. https://tsamsonov.github.io/r-geo-course/05-BaseGraphics.html
2. https://r4ds.hadley.nz/data-visualize.html
Подготовка среды
3. Установите R и RStudio (если ещё не установлено).
4. Установите необходимые пакеты:
install.packages(c("ggplot2", "dplyr", "readr"))
3. Подключите пакеты:
library(ggplot2)
library(dplyr)
library(readr)
Загрузка данных
Используйте встроенный набор данных mtcars (уже доступен в R) 
data(mtcars)
Выведите первые 6 строк, чтобы проверить структуру:
head(mtcars)
Упражнение 7.1. Создание базовых диаграмм (базовые функции R: plot, bar, 
hist, abline)
Для каждого типа диаграммы:
 постройте график;
 добавьте заголовок и подписи осей;
 измените цвет элементов (по желанию).
7.1.1. Столбчатая диаграмма (barplot):
7.1.1.1 Рассчитайте среднее значение mpg для разных значений 
количества цилиндров (cyl) (используйте tapply c mean). Группируйте по cyl, 
подсчитывая среднее mpg.
7.1.1.2. Сделайте разные цвета для столбиков. Подпишите значения. 
Добавьте легенду.
7.1.2. Круговая диаграмма (pie):
7.1.2.1. Визуализируйте долю машин с разным числом цилиндров (cyl).
7.1.2.2. Добавьте подписи с процентами. Добавьте легенду.
7.1.2.3. Для заливки долей цветом используйте rainbow.
7.1.2.4. Для заливки долей цветом используйте вектор c=("blue", "red", 
"green").
7.1.2.5. Для заливки долей цветом используйте colorRampPalette
7.1.3. Гистограмма (hist):
7.1.3.1. Постройте распределение переменной hp (лошадиные силы).
7.1.3.2. Настройте количество интервалов (breaks). 
7.1.3.4. Поменяйте единицу деления для оси Y частоты (сделайте c 
шагом 2, а не 1).
7.1.4. Диаграмма рассеяния (plot):
7.1.4.1. Отобразите зависимость mpg от wt (вес).
7.1.4.2. Добавьте линию регрессии (abline(lm(mpg ~ wt, data = mtcars))).
7.2. Продвинутая визуализация (ggplot2)
Для каждого графика:
 используйте ggplot() с указанием данных и эстетики (aes);
 добавьте геометрический слой (geom_...);
 настройте тему и подписи.
7.2.1. Точечная диаграмма с цветовой группировкой:
7.2.1.1. Постройте точечную диаграмму x = wt, y = mpg, цвет по cyl.
7.2.1.2. Добавьте сглаживающую линию (geom_smooth()).
7.2.1.3. Добавьте эллипс рассеивания для каждого класса цилиндров с 
помощью stat_ellipse
7.2.2. Ящик с усами (geom_boxplot):
7.2.2.1. Покажите распределение mpg по группам cyl.
7.2.2.2. Добавьте точки наблюдений (geom_jitter()).
7.2.2.3. Поменяйте название легенды с factor(cyl) на Цилиндры.
7.2.3. Гистограмма с фасетированием:
o Гистограмма hp для каждой группы cyl (используйте facet_wrap(~cyl)).
o Настройте прозрачность и цвет заливки.
